# Ranked Draft

Draft-hjelper for Brawl Stars ranked: velg mode, map, first pick og bans, og legg inn picks etter hvert.
På deres tur anbefaler siden picks ut fra en modell trent på ranked-kamper fra Legendary III og oppover.
Alt regnes i nettleseren. Siden er én statisk fil.

Siden: https://erlendskogan.github.io/ranked-draft/

Uoffisielt fanverktøy, ikke tilknyttet, sponset eller godkjent av Supercell.
Brawler- og map-bilder: Brawlify. Data: Brawl Stars' offisielle API.
